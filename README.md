# AuctionPlus

Расширение для стандартного окна **Аукциона** в **Аллоды Онлайн**.

Облегчает поиск и покупку предметов, а также сохраняет цены — чтобы в дальнейшем,
когда нет доступа к аукциону, можно было узнать стоимость предмета
во всплывающей подсказке.

## Возможности

### 🔍 Вкладка «Купить»
- Группированный список **всех** найденных лотов по запросу (а не только 8, как в стандартном окне) — облегчает поиск и выбор выгодного лота.
- Помимо цены выкупа лота отображается **цена за единицу** предмета.
- **Группировка:**
  - для обычных предметов — по совпадению «название + кол-во в стаке + цена за единицу»;
  - для оружия и одежды — по совпадению «название + уровень экипировки + сумма спец. характеристик + сумма характеристик + цена выкупа».
- Если сгруппировались одинаковые лоты — можно **выкупить все или только нужное количество**. Количество указывается в баре под списком (появляется при клике по позиции); цена пересчитывается сразу (цена × кол-во).

### 💾 База цен и тултипы
- Пока открыто окно аукциона, аддон **записывает в свою базу** цены на всё, что отображается по результату любого поиска.
- Сохранённые цены показываются во всплывающей подсказке предмета.

### 📊 Сканирование аукциона
Кнопка **«Сканировать»** рядом со вкладками. Три варианта (выбираются в настройках):
1. **Полное сканирование аукциона** — долго, зависит от количества страниц; прерывается кнопкой «Остановить».
2. **Только по предметам в сумке** — составляет список всех предметов в сумке и по порядку ищет их на аукционе; на экране появляется перемещаемое окно со списком.
3. **Свой список** — при открытии окна аукциона появляется окно, где можно составить свой список предметов для поиска и записи цен. Также открывается из настроек аддона.

### ⚙️ Настройки
Открываются из стандартного окна включения/выключения аддонов или командой в чате `/opl`. Можно:
- выбрать вариант сканирования;
- посмотреть/редактировать свой список для сканирования;
- очистить базу сохранённых цен;
- выбрать отображение минимальной и максимальной стоимости;
- выбрать стиль текста для добавляемых строк во всплывающей подсказке;
- выбрать вариант отображения «монет» (только золото / золото и серебро / все монеты).

## Установка

1. Скачайте последний релиз из [Releases](../../releases) (или клонируйте репозиторий).
2. Распакуйте в папку аддонов Аллодов Онлайн:
<Папка игры>/data/Mods/Auction+/

3. Перезапустите игру или перезагрузите аддоны через менеджер.
